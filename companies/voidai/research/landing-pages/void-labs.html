For Developers

Build with Void

Integrate bridge, staking, and lending directly into your application. Full SDK with TypeScript support.

View Documentation GitHub
// Initialize Void SDK
import { Void } from '@void/sdk'
// Bridge TAO to Solana
const tx = await void.bridge({
from: 'bittensor',
to: 'solana',
amount: 100,
token: 'TAO'
})
// Deposit into lending
await void.lend.deposit({
asset: 'USDC',
amount: 10000
})
